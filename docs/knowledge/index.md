# Dabbarha Knowledge Base

This directory contains Dabbarha-owned documentation that is used for retrieval-augmented generation (RAG).

## Approved Documents

Only documents in this directory are indexed for RAG. The chatbot may retrieve and reference these documents when answering questions about Dabbarha product rules, features, and policies.

## Documents

- `affordability.md` — Dabbarha affordability classification rules and thresholds
- `forecast.md` — How Dabbarha forecasting works
- `obligations.md` — Obligation properties, statuses, and ownership rules
- `chatbot.md` — Dabbarha chatbot capabilities and security model
- `security.md` — Dabbarha security model and data protection principles

## Restrictions

- No personal financial data is stored in this directory.
- No user-specific information is indexed.
- No arbitrary files from outside this directory are included.
- This directory is not indexed into the RAG corpus automatically; only explicitly approved documents are ingested.
